# 最终审查清单

这份清单用于在提交 `.drawio` 前做最后一轮自检。

## 1. 结构正确性

- 图种选对了吗
- 每条边的语义明确吗
- 是否有漏连、错连、悬空边
- 复杂关系是否应该拆页

## 2. 连线质量

- 是否存在 `edge_crossing`
- 是否存在 `edge_through_node`
- 主流程边是否最直、最短、最容易读
- 分支是否在视觉上有序展开
- 边标签是否离拐点太近

## 3. 遮挡与拥挤

- 是否存在 `node_overlap`
- 文本是否被截断
- 容器标题是否被边压住
- 图例、注释、角标是否挡住主内容
- 重要图标是否被边切开

## 4. 样式质量

- 是否选定了明确的视觉系统
- 颜色是否有语义而不是随便上色
- 标题、正文、注释是否有明确层级
- 同类元素是否真正一致
- 是否陷入默认 AI 同质化风格
- 是否具有文档级成品感，而不是草图感
- 是否显式设置了更稳定的字体
- 背景是否应当透明而不是纯白
- 是否还保留了多余装饰或重复图标

## 5. 多页一致性

- 页面命名是否一致
- 颜色体系是否一致
- 容器语言是否一致
- 线型是否一致
- 细节密度是否一致

## 6. 工具链检查

建议顺序：

```bash
python scripts/drawio_tools.py summary path/to/file.drawio
python scripts/drawio_tools.py lint path/to/file.drawio
bash scripts/convert-drawio-to-png.sh path/to/file.drawio
```

## 7. 交付标准

只有在满足下面条件时，才应该认为图已经完成：

- 没有明显连接错误
- 没有明显遮挡
- 没有不必要的交叉
- 图面有明确节奏和层次
- 风格不是随手默认值
