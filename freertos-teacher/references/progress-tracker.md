## 费曼检验记录

### 2026-07-12 | 02_task_basics | 任务优先级与抢占
- 用户表述：同优先级时间片轮转；高优先级阻塞后低优先级才能运行；提高优先级后低优先级可能永远不执行
- 评分：7.5/10
- 正确部分：同优先级时间片轮转；高优先级阻塞时低优先级可以运行
- 错误/遗漏：漏说同优先级是时间片轮转也能交替；提高优先级不会导致低优先级"永远不执行"，只要高优先级阻塞就能跑
- 更准确表述：同优先级靠时间片轮转；不同优先级靠抢占，但高优先级阻塞时低优先级立刻补上

### 2026-07-12 | 02_task_basics | 任务状态（四种状态 / osDelay 不加的后果）
- 用户表述：osDelay 后整个系统进入阻塞态；不加 osDelay 会进入阻塞态但不知后果
- 评分：5.5/10（第一题 6 分，第二题 5 分）
- 正确部分：知道不加 osDelay 不会进入阻塞态
- 错误/遗漏：osDelay 只影响当前任务而非"整个系统"；不加 osDelay 会导致 CPU 无法空闲、无意义翻转
- 更准确表述：osDelay 只让当前任务阻塞；不加 osDelay 任务永远留在就绪/运行态，霸占 CPU 做无意义工作

### 2026-07-12 | 01_concepts | osDelay vs HAL_Delay / 任务切换机制
- 用户表述：osDelay 让 CPU 空闲，HAL_Delay 堵塞 CPU；两个任务是快速切换，LED 翻转后切默认任务，默认任务结束后切回 LED
- 评分：6.5/10（第一题 6 分，第二题 7 分）
- 正确部分：理解了 osDelay 让出 CPU 的核心思想；理解了任务不是同时运行而是快速切换
- 错误/遗漏：osDelay 时 CPU 不是空闲而是执行其他任务；切换发生在 osDelay() 主动让出，不是任务"结束"
- 更准确表述：osDelay 是"你们先忙，我歇会儿"；切换发生在 osDelay() 调用时，同优先级还有时间片轮转

### 2026-08-04 | 02_task_basics 逾期复习（距上次 18 天）| 概念口述 + 变体场景
- 四态口述：说了"删除态"（不存在），漏了挂起态和阻塞/挂起区别
- 评分：7/10（良好）
- 正确部分：osDelay 让出 CPU 本质（9/10）；vTaskDelayUntil 绝对周期（8/10）
- 错误/遗漏：四态记忆（5/10）；同优先级切换机制误认为等 osDelay，实为时间片轮转；变体场景答错"系统节拍崩溃"（实际 tick 照常，是低优先级任务饿死）
- 更准确表述：阻塞是"等闹钟自动醒"，挂起是"被暂停必须别人叫"；SysTick 是中断，任务忙等不影响 tick

### 2026-08-04 | 03_scheduling | 课1 抢占式 vs 协作式
- 用户表述：抢占式实时性强、重要任务插队；协作式下 HAL_Delay 忙等会卡死在 LED 任务
- 评分：9/10（优秀）
- 正确部分：抢占式插队价值；协作式"靠自觉"一旦忙等全盘卡死
- 补充：协作式下高优先级任务也无法抢占，调度器根本不切换

### 2026-08-04 | 03_scheduling | 课2 临界区（初答 3/10 后重讲，再检验 7.5/10）
- 初答：不知为何必须短，说"调度器会崩溃"（实为死锁非崩溃）
- 重讲后填空：关所有中断 → SysTick 不触发 → tick 不递增 → 延时永不到期 → 任务阻塞 → 系统冻结
- 评分：7.5/10（良好）；遗留：④⑤层级混淆（任务阻塞 vs 系统死锁），"崩溃"应为"死锁冻结"
- 更准确表述：临界区关的是全部中断含 SysTick；临界区必须短 = 心跳停摆 + 事件丢失 + 实时性归零；临界区内严禁阻塞 API

### 2026-08-04 | 04_queue | 课1 队列基础（一次通过）
- 用户表述：队列自动适配任务快慢；全局变量两个任务间传数据会冲突+抢占导致数据错；空队列阻塞释放 CPU；拷贝是为了数据隔离
- 评分：8.5/10（优秀）
- 正确部分：阻塞机制适配快慢；裸机轮询 vs RTOS 阻塞对比；拷贝语义隔离
- 补充：传指针最致命的隐患是指针悬空（局部变量地址失效变野指针），所以 FreeRTOS 用拷贝语义

### 2026-08-04 | 04_queue | 课2 ISR 通信（一次通过）
- 用户表述：中断阻塞会卡死、中断要快进快出；pxHigherPriorityTaskWoken 在有高优先级任务阻塞等数据时置 pdTRUE 并切换过去
- 评分：9/10（优秀）
- 正确部分：中断不能阻塞的核心原因；任务唤醒参数机制链完整
- 补充：队列是共享资源非"某任务专属"；完整链 = FromISR 发送 → 置 woken → portYIELD_FROM_ISR → 出中断立即切换
