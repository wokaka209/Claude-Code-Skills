## 学习笔记

<!-- 记录学习过程中的心得、易错点、实用表达 -->

### 易错点
- commit 日常意思是"承诺"，不是"承认"
- CD 是 Continuous Deployment（持续部署），不是"持续开发"
- PR 是请求别人合并你的代码，不是让别人下载
- front-end 是"前端"，不是"格式"（format）
- shipping 是"交付/部署"，不是"分发"（distribute）
- sub- 前缀意思是"子级的/从属于"，不是"在下面"
- based on 修饰前面整个动作，不是最近的名词

### 实用表达
- "Feel free to open an issue" — 尽管提 issue
- "We appreciate your contribution" — 感谢贡献
- "This project aims to..." — 本项目旨在...
- "through a user-friendly front-end" — 通过友好的前端
- "based on standard Python type hints" — 基于标准 Python 类型注解
