# 布局与图种规则

## 1. 通用规则

### 1.1 主流程方向要统一

优先选择单一主方向：

- 左到右：架构图、数据流、时序前置说明
- 上到下：审批流、流程图、时间线

除非图种本身要求，否则不要在同一页里混用多个主方向。

### 1.2 先定容器，再放内容

常见容器包括：

- 云边界 / VPC / 子网 / 安全组
- 泳道
- 组件外框
- 时间线分段

先确定容器大小和留白，再放内部节点。不要先摆节点再硬套边框。

### 1.3 留白比"填满画布"更重要

经验值：

- 大块之间：40 到 80 px
- 同级节点之间：20 到 40 px
- 容器内部边距：24 到 40 px

如果图一眼看上去拥挤，优先加留白，而不是缩小字体。

## 2. 连线规则

### 2.1 默认优先正交线

大多数技术图里优先：

- `edgeStyle=orthogonalEdgeStyle`
- 少拐弯
- 少交叉

只有在时序图、攻击树、某些关系图里，才优先曲线或特殊线型。

### 2.2 标签不要压在线上

边标签应：

- 明确附着于某条边
- 避开拐点
- 不覆盖节点标题

如果需要，把标签稍微偏移，而不是缩小到不可读。

### 2.3 箭头不要穿框穿字

如果连线穿过这些内容，通常说明布局还没整理好：

- 容器标题
- 组件名称
- 泳道标题
- 图例

### 2.4 连线交叉优先通过重排节点解决

如果存在交叉，先尝试：

- 移动节点
- 调整分组
- 打开通道
- 拆成两页

不要第一反应就是继续给线增加拐点。

### 2.5 主流程边要明显优于辅助边

主流程边应：

- 更直
- 更短
- 更少拐弯
- 更少被其他元素打断

## 3. 字体与文本

### 3.1 用少量字号层级

推荐只保留 3 档：

- 标题：18 到 24
- 节点正文：12 到 16
- 注释：10 到 12

不要在同一页里出现太多字号。

如果目标是文档、博客或幻灯片中的成品图，字号默认应比"勉强看清"更大一档。

### 3.2 标签长度要服从图种

- 组件图、架构图：名称尽量短
- 流程图：动作短语清晰
- 时序图：消息文本尽量一行
- 思维导图：单节点只表达一个点

如果文本过长，先改文案，再考虑放大节点。

### 3.3 留出标签缓冲区

节点周围应留出足够空白，使连线和标签不会紧贴边缘。

经验上：

- 普通节点四周至少留 12 到 20 px 呼吸空间
- 主节点或标题块四周至少留 20 到 32 px

### 3.4 字体要显式而不是隐式

如果一页图文字较多，尽量显式设置：

- `defaultFontFamily`
- 节点文字的 `fontFamily`

这会明显改善不同平台和导出结果的一致性。

## 4. 按图种细化

### 4.1 AWS / 架构图

- 云、VPC、AZ、子网按层级嵌套
- 外部用户、互联网、入口流量放在边界外
- 入口到计算层再到存储层，路径要能一眼看懂
- 同类资源对齐，避免"左右高低乱跳"

### 4.2 BPMN / 活动图 / 工作流

- 泳道标题高度统一
- 决策节点必须有清晰的条件标签
- 开始、结束节点位置要稳定
- 分支与汇合不要混成同一种视觉表达

### 4.3 时序图

- 参与者头部对齐
- Lifeline 垂直向下
- 激活框宽度统一
- `alt`、`loop` 等 frame 的标签位置一致

### 4.4 类图 / 组件图

- 同层元素尽量对齐
- 依赖、实现、组合、聚合的箭头样式要区分
- 说明性小图标不要喧宾夺主
- 组件图里的接口点、端口和依赖方向必须明确

### 4.5 状态图

- 初始状态和结束状态要醒目
- 状态名用名词或短语
- 迁移条件写在边上，不要塞进状态块里
- 恢复或异常路径单独留出空间

### 4.6 思维导图 / 鱼骨图 / 依赖图

- 保持一套分支节奏
- 同层分支长度和间距尽量一致
- 因果图不要把次级原因画得比主干还重

## 5. 多页一致性

多页文件要统一这些内容：

- 页面命名方式
- 字号层级
- 主色与辅助色
- 箭头风格
- 容器命名风格

一组多页图应该像一套图，而不是几张无关草图。

## 6. 去同质化要求

如果用户没有指定风格，新建图时至少在这些维度里主动控制 2 到 3 个：

- 容器语言
- 颜色关系
- 标题体系
- 线型和边角
- 注释块样式

但变化必须受控，不要把页面做成风格拼盘。

## 7. 导出前检查

导出 PNG 前至少检查：

- 文字是否被截断
- 箭头是否压线压字
- 容器标题是否贴边
- 页边距是否过小
- 同类元素是否对齐
- 是否仍有不必要的线段交叉
- 是否仍有节点遮挡
- 字号是否偏小
- 容器标题是否缺少呼吸空间
